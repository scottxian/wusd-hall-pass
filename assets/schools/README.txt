Hall Pilot school logo assets

Place school logos in this directory and register them in /branding.js using a
two-part organization/school key, such as wusd/westfield.

Expected Westfield logo: wusd--westfield.webp
The optimized Westfield logo is included in this folder.

Missing or unregistered logos are hidden; the school name remains visible.
The registry is a static configuration. Admin logo uploads are not yet supported.
